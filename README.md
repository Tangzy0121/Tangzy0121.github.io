# Tangzy's Blog

A personal notebook for programming contests, data science, computer science, and occasional reflections.

## Local development

```bash
npm install
npm run dev
```

The current edition contains:

- a personal home page;
- a compact notebook index and article pages with a table of contents;
- category, tag, and archive views;
- IBM Plex typography and a Carbon-inspired technical reading system;
- an intentionally quiet projects page;
- a short about page.

The existing `harmony-agent-demo.mp4` in this repository is preserved.
